# EMA 進場訊號有效性分析

這次先回答一件事：EMA 進場後，價格是否通常朝預期方向走，而且幅度足夠支付交易成本？這是研究診斷，不是新的交易策略，也不是 XTX 的模型重現。

## 事先固定的比較方式

- 沿用 `market_data_20261011.zip`，校驗兩份公開行情 CSV 的 SHA-256；不使用私人交易資料。
- 使用原研究引擎的 1h EMA20／60 方向、15m EMA5／20 交叉及 0.15% 防追價條件。訊號只讀已收盤資料，在下一根 15m K 線開盤評估進場。
- 分別在進場後 15、30、60 分鐘的開盤價評估報酬。所有長度只使用有完整 60 分鐘後續資料的同一批訊號；終點不得跨出所屬期間，也不使用快照外價格。
- 不加停利、停損、倉位或每日停手機制；每個合格訊號都獨立觀察，持有期間可以重疊。因此訊號數不等於策略實際成交數，平均報酬不能相加為帳戶報酬。
- 毛報酬為方向調整後的價格變化；淨報酬模擬每邊 0.05% 手續費與 0.025% 不利滑價，並計入持有期間的歷史資金費。另列手續費、滑價加倍情境，資金費不加倍。
- 報酬分母一律為未加滑價的進場名目金額，不加槓桿。用基點（bp）表示，1 bp = 0.01%。價格不動時基本來回成本為 15 bp，壓力情境為 30 bp。
- 資金費採與原引擎一致的時間慣例：不收取進場同時的資金費，計入出場同時的資金費。這是模擬慣例，不代表交易所保證能在結算邊界成交。

## 分段與對照

沿用前次開發、驗證、較後段歷史、9/28–10/4 診斷週及 10/5 起新增期間。這些資料已被之前的研究看過；「驗證」是原有區間名稱，本次不能把它宣稱為全新樣本外結果。

除整體結果外，保留多空、1h ADX14≥25／<25，以及高低波動分組。波動以已收盤的 15m ATR14／收盤價衡量，高低分界只用開發期間所有可用 K 線的中位數，後續區間不重估。ADX 的分組只是操作定義，不保證正確辨識市場狀態。分組沒有用來選參數或停用某方向。

另設一個簡單毛報酬對照：同區間所有符合終點要求的 15 分鐘開盤時點，以該區間 EMA 訊號的多空比例加權其後報酬。它幫助辨認整段市場偏漲／偏跌的影響，但沒有配對時段、波動或流動性，亦非可執行策略，不能當作因果證據。分組表不使用這個整體對照。

## 不確定性

整體平均毛／淨報酬附探索性的 95% 區間：將每日訊號的報酬總和與數量按連續 7 個日曆日區塊重抽樣 2,000 次，再計算訊號加權平均，亂數種子固定為 20261011。無訊號日也保留；少於 30 個訊號或少於 28 個日曆日不提供區間。

這能部分保留重疊訊號與短期相依性，但不能消除更長期相依、行情非定態或重複研究造成的偏差。沒有對多期間、多長度及分組進行多重比較校正，也不以某個區間剛好高於零作為採用條件。短週樣本只作描述，勝率不等於獲利能力。

## 重現

在儲存庫根目錄，先安裝既有 `requirements.txt`：

```bash
python -m zipfile -e research/market_data_20261011.zip research/data_20261011
python research/signal_quality.py
python research/write_signal_report.py
python -m unittest discover -s tests -v
```

輸出 `signal_results_20261011/events.csv` 是公開行情推導的逐訊號研究資料，不是帳戶交易紀錄；`summary.csv` 包含全部分組，`method.json` 保存資料雜湊和固定設定。未訓練機器學習模型，也未更動下單程式。
