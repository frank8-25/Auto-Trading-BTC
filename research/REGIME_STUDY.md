# 2026-10-12：依行情選策略的固定實驗

本輪先固定下面的假設，再跑結果，不在看見結果後追加參數搜尋。使用截至 2026-10-11 13:15 UTC 的既有公開快照；這批歷史已被之前研究看過，因此全部仍是探索。沒有新增真實樣本外證據，也不自動部署。

## 原因與假設

前次 506 個 EMA 訊號在 15／30／60 分鐘未呈現穩定且足以支付成本的優勢。基本來回成本約 0.15%，相對 0.3% 停利很大；以固定 0.3% 盈利、0.5% 虧損與每筆約 0.15% 成本粗估，損益兩平勝率約 81.25%，但 EMA 提早出場、滑價及資金費會改變這個數字，不能直接套在實際成交上。

本輪測試三個假設：拉長訊號尺度能否減少短期雜訊；ATR 出場能否提供較合理的波動空間；用當下已知的 ADX 分類能否改善不同策略的搭配。技術指標分類可能錯判，不能事後替每筆交易選行情標籤。

## 固定候選

所有小時指標只使用完整收盤小時。突破通道不包含訊號 K 線本身；小時訊號僅在收盤後第一個 15 分鐘開盤使用一次。最大持倉時間在下一根開盤檢查，不延後硬停損。

| 名稱 | 進場 | 出場 |
|---|---|---|
| baseline | 原 EMA 規則 | 原 0.5% 停損／0.3% 停利／反向交叉 |
| ema_atr | 原 EMA 規則 | 2 倍 15m ATR，最低 0.4%、超過 2% 不開倉；2.5R 停利；24 小時退出；不因 EMA 交叉退出 |
| breakout20 | 1h ADX≥25、EMA20／60 同向，收盤突破前 20 小時高低 | 2 倍 1h ATR，最低 0.6%、超過 3% 不開倉；3R 停利；反向突破前 10 小時通道或 48 小時退出 |
| breakout40 | 同上，進場通道改為 40 小時 | 與 breakout20 相同，作預先固定的鄰近參數檢查 |
| pullback | 1h ADX≥25、EMA20／60 同向，收盤從 EMA20 另一側回到趨勢側 | 1.5 倍 1h ATR，最低 0.5%、超過 2.5% 不開倉；2.5R 停利；1h 趨勢反向或 24 小時退出 |
| range_reversion | 1h ADX<20，沿用 15m 布林回帶＋RSI 訊號 | 2 倍 15m ATR，最低 0.4%、超過 1.5% 不開倉；1.5R 停利；RSI 回到 50 或 6 小時退出 |
| switch20 | ADX≥25 用 breakout20，ADX<20 用 range_reversion；20–25 不開新倉 | 開倉時確定該筆交易的出場規則，不因之後分類改變而換規則 |
| switch40 | 同上，趨勢分支用 breakout40 | 同上 |

## 評估與排序先固定

- 沿用原引擎：初始模擬資金 10,000、每筆 1% 風險預算、每日 2% 已實現虧損預算、最多 2 倍名目曝險、0.001 BTC 數量步進。這是模擬風控，不保證跳空時損失受限。
- 費率每邊 0.05%、滑價每邊 0.025%，加歷史資金費；另將費率及滑價加倍。停損與停利同根觸及時，保守認定停損先發生。回撤使用 15m 收盤權益，非逐筆極值。
- 開發期 2025/10/01–2026/04/01，驗證期 04/01–07/01，後段檢查 07/01–09/28；09/28–10/11 13:15 為短期診斷。各區間獨立起算與結算。
- **候選先以開發期加倍成本淨報酬排序**，同分依較低回撤、再依名稱。最佳主動候選仍可能虧損，另與 cash 比較。不用驗證與後段挑出開發期冠軍。
- 通過歷史篩選須在開發、驗證、後段兩種成本下皆正報酬、PF>1.1、每段至少 30 筆交易，且收盤最大回撤≤15%。這是研究門檻，不是獲利保證。
- 附每月重新選擇的模擬：只用前 3 個已結束月份，每種成本須合計正報酬、PF>1.1、至少 20 筆，且三個月各月回撤≤15%；符合者按加倍成本的三個月複合報酬排序，否則持有現金。從 2026/04 起跑到 09 月。每月獨立起算、月底強制結算，再複合月報酬；不是持倉跨月的連續引擎，訓練的 PF 以各月固定資本交易合計計算。

保留全部嘗試、進場時行情分類、月度表及選擇理由。若所有版本都失敗，結果就是尚無合格交易策略，不把「這批裡少虧」當成「可以部署」。本輪完成後保留固定實驗工具，後續新資料到達時可重跑；本次不啟動無限背景搜尋。

## 研究依據與限制

- [Moskowitz、Ooi、Pedersen：Time Series Momentum](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)：提供研究趨勢延續的方向，其原研究市場與時間尺度不同，不能當作本次 BTC 小時策略有效的證明。
- [Bailey 等：The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)：反覆搜尋可能選到只適合歷史的版本。本輪保留全候選並區分選擇與檢查期間，但沒有估計 PBO，也不能消除多次研究累積的選樣偏差。

來源查閱：2026-10-12。研究程式只使用公開資料，不讀取帳戶金鑰或下單。

```bash

python research/regime_study.py
python research/write_regime_report.py
python -m unittest discover -s tests -v
```

結果寫入 `research/regime_results_20261012/`，共 4 個長短期間、9 個月度期間、9 個版本與 2 組成本，合計 234 組。`simulated_trades.csv` 全部由公開行情產生，不是帳戶交易紀錄。`regime_attribution.csv` 使用進場時的分類。

成本加倍時，同一風險預算會縮小部位，也可能改變每日限制及之後的成交路徑；某一情境虧損較少，不代表高成本本身提高了報酬。歷史篩選的最大回撤條件是評估門檻，不是另加一個盤中強制停機。
